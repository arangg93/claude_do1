# claude_do1 — 데일리 뉴스 브리핑 자동화

매일 아침 **08:00 (KST)** 에 3개 주제의 최신 뉴스를 검색·선별해서
**이메일**과 **카카오톡 나챗방**으로 받아보는 자동화 설정.

## 무엇을 받나

총 **10건** (기본 배분, 그날 뉴스 상황에 따라 조정)

| 주제 | 기본 건수 | 관점 |
|---|---|---|
| 🎓 입시 뉴스 | 5건 | **고3 담임 / 진학부 교사** |
| 💼 1인 기업 활용 사례 | 2건 | 실행 가능한 구체 사례 |
| 🤖 최신 AI 뉴스·활용법 | 3건 | 오늘 바로 써먹을 신기능 |

입시 뉴스는 수능·모평, 수시/학종, 정시, 대학별 전형 변화, 교육부·평가원 발표,
의대 정원, 학생부 기재요령을 축으로 검색한다.

각 항목은 **제목 / 요약 / 🎯 현장 함의 / 출처+링크** 4줄 구조로 정리된다.
여기서 핵심은 **현장 함의** — "그래서 교사가 뭘 해야 하는가"이다.

## 배달 경로

- **카카오톡** → 나챗방 메모챗 (MCP)

  - 카카오는 제목·액션만, 상세 내용과 링크는 이메일에 담는다

매일 `23:00 UTC` = `08:00 KST` 에 새 세션이 떠서 자동 실행된다.
세션이 꺼져 있어도 동작한다.
